# टर्बो 3SAT GUI सॉल्वर (Turbo 3SAT GUI Solver)

यह एक शक्तिशाली हाइब्रिड क्लासिकल-क्वांटम सॉल्वर है जो 3-SAT समस्याओं को हल करने के लिए विकसित किया गया है। इसमें GUI इंटरफ़ेस है जो Streamlit पर आधारित है।

## विशेषताएँ (Features):
- Quantum Approximate Optimization Algorithm (QAOA)
- Z3 द्वारा सत्यापन (Verification)
- Clause Heatmap Visualization
- GPU-Accelerated Local Search
- Streamlit आधारित GUI

## आवश्यकताएँ (Requirements):
- Python 3.8+
- Streamlit
- Z3 Solver
- NumPy, Matplotlib, आदि
